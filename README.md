# Smart Grocery List & Inventory Manager

A Full Stack MERN application for managing grocery inventory, tracking stock levels, monitoring expiry dates, generating shopping lists, and receiving low-stock alerts.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Tailwind CSS

## Features

- User Authentication
- Grocery Management
- Inventory Tracking
- Low Stock Alerts
- Expiry Alerts
- Shopping List Generation
- Dashboard Analytics
